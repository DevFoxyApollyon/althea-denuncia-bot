1. No bot (você)

  1. Chave mestra: use o botão Gerar chave acima (ou o comando abaixo) e deixe a mesma linha PONTE_CHAVE_MESTRA=… no .env do seu PC. A impressão mostrada aqui ajuda a conferir se os dois são iguais. 
    node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
  2. Rode npm run pacote e suba o zip novo na SquareCloud.
  3. No Discord do servidor: /ponte gamemode executor tipo: Gamemode (ou "Os dois" para manter o PC durante a troca).
  4. /ponte gamemode criar nome: <nome do servidor> (com ips: quando souber os IPs de saída do servidor do jogo). O bot manda o arquivo althea_credenciais.txt uma vez só.

2. Na gamemode (devs do servidor)

Arquivos: pasta gamemode/ no GitHub (v3.12.0). Versão atual do include: .

  1. Instale o plugin pawn-requests e o requests.inc.
  2. Copie gamemode/althea_ponte/ (os 3 arquivos .inc) para a pasta de includes.
  3. No topo da gamemode, nesta ordem: 
    #include <requests>

#define ALTHEA_MODO_TESTE (true)
#define ALTHEA_MAX_BAN_DIAS (30)
#define ALTHEA_PERMITIR_BAN_PERMANENTE (true)
#define ALTHEA_MAX_CADEIA_MIN (300)
#define ALTHEA_MAX_POR_HORA (30)
#define ALTHEA_DEFINIR_ONREQUESTFAILURE
#include "althea_ponte/althea_ponte"

    ALTHEA_PERMITIR_BAN_PERMANENTE vem false no include: sem esta linha, o ban permanente que o bot libera é recusado (DADOS_INVALIDOS). Se a gamemode já tem OnRequestFailure, tire o ALTHEA_DEFINIR_ONREQUESTFAILURE e chame Althea_FalhaRequisicao(id); dentro dele.

  4. Ligue nos callbacks: 
    public OnGameModeInit()  { Althea_Iniciar();  /* ... */ }
public OnGameModeExit()  { Althea_Encerrar(); /* ... */ }
public OnRconCommand(cmd[]) { if (Althea_ComandoRcon(cmd)) return 1; /* ... */ }
  5. Crie a tabela althea_pedidos (SQL no topo de gamemode/exemplo/exemplo_gamemode.pwn). A chave primária impede aplicar o mesmo pedido duas vezes.
  6. Escreva Althea_Aplicar() seguindo o exemplo, trocando as funções marcadas com TROQUE (Gm_Banir, Gm_Prender, Gm_DarAvisos, Gm_Desbanir, Gm_Soltar e a consulta da conta) pelas da gamemode. Staff responde ALTHEA_CONTA_PROTEGIDA. Tudo precisa funcionar com o jogador online e offline.
  7. Salve o arquivo do bot em scriptfiles/althea_credenciais.txt (fora do git), compile e suba a gamemode.

3. Testar e ligar de verdade

  1. Confira acima: a coluna Gamemode fica ● online quando a gamemode busca pedidos. No jogo, rcon althea status.
  2. Aceite uma denúncia, clique em Enviar ao jogo no embed do Relatório de punições e veja o 🧪 simulado. Confira por alguns dias.
  3. Só aplica de verdade com o modo teste desligado nos dois lados: /ponte gamemode limites (modo teste = não) e rcon althea teste 0. Solte aos poucos: cadeia, depois ban curto, por último permanente.
  4. Quando souber os IPs do servidor do jogo: crie uma credencial nova com ips:, troque o arquivo no servidor (rcon althea recarregar, sem reiniciar) e revogue a antiga.

RCON: althea status, althea pausar, althea retomar, althea teste 1, althea teste 0, althea recarregar.
